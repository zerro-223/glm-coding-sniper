# 🔥 GLM Coding Plan 抢购助手

智谱 AI 开放平台 GLM Coding Plan 自助抢购油猴脚本，支持**定时触发**、**高并发重试**、**数据拦截造假**。

## 原理

在底层拦截并篡改服务器返回的数据流：劫持 `JSON.parse` / `fetch` / `XHR`，将 `isSoldOut`、`disabled` 等属性强制改为 `false`，让页面原生激活支付按钮，绕过前端限制。

同时以多路并发 + 自适应间隔持续发送 preview 请求，拿到 `bizId` 后立即 check 校验 → 锁单成功 → 触发支付。

## 功能

| 模块 | 说明 |
|------|------|
| 控制面板 | Shadow DOM 隔离，可拖拽/最小化，配置持久化 |
| 请求拦截 | 劫持 JSON.parse + fetch + XHR，数据造假 + 参数捕获 |
| 并发引擎 | 3 阶段自适应间隔，双轨并发（极速 10 路 / 普通 5 路），preview→check 流水线 |
| 反检测 | 请求指纹随机化、toString 伪装、频率抖动 |
| 高精度定时 | rAF + performance.now，服务器时间校准（RTT 修正） |
| 支付恢复 | 4 层递进策略：清除遮罩 → 重新点击 → 直接获取支付链接 → Vue 组件树兜底 |
| 验证码监控 | MutationObserver 检测 + 高亮提醒 + 声音/通知告警 |

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 Tampermonkey 图标 → **添加新脚本**
3. 将 `glm-coding-sniper.user.js` 的全部内容粘贴进去
4. `Ctrl+S` 保存

## 使用

1. 打开 [bigmodel.cn](https://www.bigmodel.cn/) 的 GLM Coding Plan 套餐页面
2. 右下角出现控制面板，选择目标套餐和付费周期
3. 在页面上**点击一次购买按钮**，让脚本捕获请求参数
4. 选择模式：
   - **开始监控** — 设定开抢时间，到时自动触发
   - **立即抢购** — 立即开始并发抢购
5. 抢到后会自动弹窗/播放提示音/发送浏览器通知

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt+S` | 开始监控 |
| `Alt+X` | 停止/重置 |
| `Alt+H` | 隐藏/显示面板 |

### 配置项

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 开抢时间 | `09:59:58` | 定时触发时间 |
| 提前量 | `200ms` | 提前触发补偿延迟 |
| 极速并发 | `10` 路 | 前 5 秒并发数 |
| 普通并发 | `5` 路 | 5 秒后持续并发数 |
| 最大重试 | `2000` 次 | 总重试上限 |
| 极速爆发 | `20` 次零延迟 | 开抢瞬间零间隔 |
| 捡漏窗口 | `5` 分钟 | 超时自动停止 |
